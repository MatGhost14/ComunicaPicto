# `lib/services/`

Servicios de plataforma, aislados del resto de la aplicación para que los repositorios y
los ViewModels dependan de una interfaz y no del plugin concreto.

Vacío en la HU1. Alojará, entre otros:

- **TTS** — síntesis de voz en español (HU3).
- **Seguridad** — cifrado y PIN del modo de administración protegida (HU14/HU15).
- **Imágenes** — captura y almacenamiento de pictogramas personalizados.
